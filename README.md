# Stone-Paper-Scissors

A simple Rock-Paper-Scissors game made using HTML, CSS, and JavaScript.

## How to Play

1. Open `html.html` in your browser.  
2. Click on **ROCK**, **PAPER**, or **SCISSORS**.  
3. The computer will randomly pick its choice and the winner will be displayed.  

## Features

- Simple and interactive UI  
- Dark theme design  
- Pure JavaScript logic for game functionality  

## Files

- `html.html` → Main HTML file  
- `style.css` → Styles for the game  
- `js.js` → Game logic  

it is designed with random function
